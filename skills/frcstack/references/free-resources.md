# Free references and local CAD execution

When the user has no models, select suitable public references rather than stopping all work. Record owner, season, version and usage terms. Free viewing does not establish redistribution or model-training permission. Do not modify another owner's public CAD document.

| Resource | Use |
|---|---|
| [FIRST 2026 KitBot](https://www.firstinspires.org/resources/library/frc/kitbot) | Complete baseline CAD, drawings and assembly documentation. Its [STEP file](https://firstfrc.blob.core.windows.net/frc2026/KitBot/KB-2026-rev.step) can be inspected locally without Onshape authentication. Link FIRST content; do not re-host it here. |
| [Robonauts Everybot](https://www.118everybot.org/) | Team-published robot references across seasons. [2026 resources](https://www.chiefdelphi.com/t/the-2026-robonauts-frc-everybot-low-resource-build/510331) link CAD, BOM, build documentation and generators. |
| [FRCDesignLib](https://www.frcdesign.org/resources/frcdesignlib/) | Community COTS components/assemblies through FRCDesignApp. Verify vendor, variant and critical interfaces. |
| [KrayonCAD](https://frcdesign.org/resources/krayoncad/) | Configurable simplified subsystems for layout/packaging, not detailed manufacturing CAD. |
| [Spectrum 3847 seasons](https://www.spectrum3847.org/seasons/) | Team-specific development records and CAD/code. |
| [Citrus Circuits releases](https://www.citruscircuits.org/cad-code-release) | Team CAD/code/strategy; verify actual document year/version. |

Preserve asset-specific notices and provenance. Do not bundle models with unclear redistribution terms. Reading references is not training model weights. Start with sourced engineering cases and held-out tests; actual fine-tuning requires a permitted dataset, an accessible training system and evidence of benefit.

## Optional local helper

`scripts/cad_runtime.py` creates real BRep solids and STEP exports, or inspects an existing STEP file. It is a CPU-based intermediate execution path, not an Onshape connector or whole-robot generator. It does not download models, sign in, upload, train a model, or overwrite an existing output directory.

Tested environment: Python 3.12 and CadQuery 2.8.0, isolated from global Python. From a repository checkout:

```sh
python -m venv .venv-cad
# Windows below; use .venv-cad/bin/python on Linux/macOS.
.venv-cad/Scripts/python.exe -m pip install cadquery==2.8.0
.venv-cad/Scripts/python.exe skills/frcstack/scripts/cad_runtime.py build-fixture --output .frcstack/fixture-001
.venv-cad/Scripts/python.exe skills/frcstack/scripts/cad_runtime.py inspect-step path/to/reference.step --report .frcstack/reference-inspection.json
```

An installed skill has the same helper under its own `scripts/` folder. The normal installer does not install the large optional kernel dependency. Do not change global packages or Windows settings for this workflow.

`build-fixture --parameters parameters.json` accepts the millimetre fields in `FixtureParameters`. It generates an original roller, shaft and two plates to exercise real parameter regeneration, volumes, interference and STEP read-back. These are test dimensions, not fabricated vendor parts. Bearings, retention, drive hardware, materials and manufacturing tolerances are unspecified.

Outputs are `fixture.step`, `parameters.json`, and `validation.json`. Use a new directory for each revision. Read validation evidence, not just the file extension. STEP preserves solids, not a native Onshape parametric feature history or mates; retain Python source and parameters. Sampled poses of an axisymmetric roller do not prove continuous collision-free motion. Valid solids do not establish strength, handling performance or fabrication readiness.

The final goal still requires verified native Onshape authoring, actual assembly/mate behavior, exact component interfaces, suitable structural studies and a complete benchmark robot. Importing a downloaded robot successfully is reference evidence, not a robot generated by FRCstack.

An original [native FeatureScript fixture](native-fixture.md) is also included. Its four-solid geometry and limited native revolute test have been executed in an authorized Onshape document. Re-run the capability check for each host; no login, API access, completed robot or FEA capability is supplied by installing the skill.
