# Primary source starting points

Resolve current materials for the selected program/season at task time; these links are discovery entry points, not frozen rules or an installed integration. Checked October 26, 2026. Do not rehost FIRST manuals when the publisher prohibits redistribution.

- FRC game/season: https://www.firstinspires.org/programs/frc/game-and-season
- FRC season materials and updates: https://www.firstinspires.org/resources/library/frc/season-materials
- FTC game/season/manual and updates: https://ftc-resources.firstinspires.org/ftc/game
- FIRST FRC event API: https://frc-api-docs.firstinspires.org/
- The Blue Alliance API: https://www.thebluealliance.com/apidocs/v3
- FRCDesignLib and FRCDesignApp maintainer documentation: https://www.frcdesign.org/resources/frcdesignlib/
- Onshape FIRST resources, FRC and FTC library links: https://www.onshape.com/en/education/first-robotics
- FIRST FRC technical resource directory: https://www.firstinspires.org/resources/library/frc/technical-resources
- Onshape developer documentation: https://onshape-public.github.io/docs/
- Onshape API/workspace architecture: https://onshape-public.github.io/docs/api-intro/
- Onshape authentication: https://onshape-public.github.io/docs/auth/apikeys/
- Onshape FeatureScript: https://cad.onshape.com/FsDoc/intro.html
- Onshape Feature Studio help: https://cad.onshape.com/help/Content/FeatureStudio/feature_studios.htm
- Onshape custom-feature scope: https://cad.onshape.com/help/Content/PartStudio/add_custom_features.htm
- COLMAP reconstruction assumptions/workflow: https://colmap.github.io/tutorial.html

Official APIs may require independently configured credentials; a link is not authorization or a working connection. FIRST score details do not expose in-progress match scores. Read the current documentation before choosing an ingestion route. Team/vendor source CAD, firmware/logs, datasheets, and rule evidence must be separately identified for each task.
